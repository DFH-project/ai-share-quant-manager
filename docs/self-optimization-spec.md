# A股量化系统自我优化机制 v1.0

## 核心原则
每日2:00自动执行全系统审视，基于当日操作结果强制迭代策略，零容错。

## 一、监控层优化
- 信号触发：从"数据播报"改为"行动指令"
- 止损线-15%强制提醒减仓50%，-20%清仓
- 异动股识别后5秒内输出"追涨/观望/放弃"明确判断
- 持仓股反弹至成本价上方5%立即提醒止盈

## 二、决策层优化
- 每日收盘生成"明日行动清单"（最多3条）
- 买入信号必须附带"止损位+目标位+仓位建议"
- 板块轮动识别后自动匹配持仓股关联度，输出调仓建议
- 拒绝模糊表述，所有建议必须包含具体价格和数量

## 三、执行层优化
- 记录每一次建议的实际结果（命中/miss）
- 命中率低於60%的策略自动降级，连续3日负收益策略暂停
- 建立"错误日志"：漏报、误报、延迟报全部记录并分析根因
- 每周生成策略效能报告，排名后20%的策略重写逻辑

## 四、代码层优化
- 每日2:00执行静态检查：异常捕获、边界条件、空值处理
- 数据源异常时自动切换备用源，超时10秒未响应则跳过该轮
- 所有监控脚本增加自我检测：输出格式校验、关键字段完整性检查
- 版本回滚机制：新策略上线前保留上一版本，异常时30秒内回切

## 五、复盘层优化
- 收盘后自动比对"建议vs实际"，计算当日胜率
- 浮亏持仓隔日再次评估，触发条件不改善则强制输出止损提醒
- 每月生成"策略迭代路线图"，标注已优化/待优化/废弃项
- 建立用户反馈闭环：质疑和建议24小时内响应并纳入优化队列

## 执行保障
- 2:00定时任务不可跳过，失败立即告警并重试
- 所有优化变更写入版本日志，可追溯、可回滚
- 核心决策逻辑双重校验，冲突时以用户利益优先
