## 三、操作建议 ✅

### 极高风险 (CRITICAL)
**触发条件**: 清仓式减持 / 监管立案 / 质押平仓

**输出示例**:
```
🚨 【极高风险】昭衍新药(603127)
============================================================
📰 公告标题: 股东拟清仓式减持公司股份
📂 类型: 减持
⏰ 发布时间: 2026-03-16 19:08:27
📊 风险评分: 95/100
🎯 紧急程度: 立即
📉 预估影响: 预计次日低开3-5%，甚至可能跌停

💡 建议行动: 建议立即挂单卖出50-100%仓位，清仓式减持通常导致连续跌停
============================================================
```

### 高风险 (HIGH)
**触发条件**: 大比例减持 / 业绩预减 / 大额解禁

**输出示例**:
```
⚠️ 【高风险】贵州茅台(600519)
============================================================
📰 公告标题: 股东拟合计减持公司不超5%股份
📂 类型: 减持
⏰ 发布时间: 2026-03-17 10:00:00
📊 风险评分: 85/100
🎯 紧急程度: 24小时内
📉 预估影响: 预计短期下跌5-10%

💡 建议行动: 建议减仓30-50%，设置-5%止损位
============================================================
```

### 中等风险 (MEDIUM)
**触发条件**: 一般减持 / 监管问询 / 高管变动

**建议行动**: "建议关注，若已持仓可设-3%止损，未持仓暂时观望"

### 低风险 (LOW) / 信息 (INFO)
**触发条件**: 业绩预增 / 增持回购 / 分红派息

**建议行动**: "正常持有，按原计划操作" / "仅供参考，不影响操作"
