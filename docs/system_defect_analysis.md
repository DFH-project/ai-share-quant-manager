## 为什么没提示卖出昭衍新药？

---

## 二、系统架构缺陷（根本原因）

### 2.1 监控维度单一

```
┌─────────────────────────────────────────────────────────────┐
│                    原监控体系架构                            │
├─────────────────────────────────────────────────────────────┤
│  盘中监控 (每10分钟)                                         │
│    └─> 腾讯/新浪实时行情                                       │
│         └─> 检查涨跌幅                                          │
│              └─> 超过阈值才提醒                                   │
│                                                                   │
│  深度扫描 (定时)                                               │
│    └─> 东方财富基本面                                          │
│         └─> PE/PB/ROE/财务指标                                   │
│              └─> 不检查公告                                      │
│                                                                   │
│  ❌ 没有新闻公告监控环节 ❌                                      │
└─────────────────────────────────────────────────────────────┘
```

**问题：** 系统完全依赖**价格信号**，但减持公告是**事件驱动**的。价格信号是滞后的（已经跌停了），而事件信号是前置的（公告发布时）。

### 2.2 数据层缺失

| 数据类型 | 原系统 | 问题 |
|---------|--------|------|
| 实时价格 | ✅ 腾讯/新浪 | 正常 |
| 技术指标 | ✅ 东方财富 | 正常 |
| 基本面 | ✅ 财报数据 | 正常 |
| **公告新闻** | ❌ **缺失** | **致命缺陷** |
| 资金流向 | ⚠️ 部分 | 可选 |
| 龙虎榜 | ❌ 缺失 | 次要 |

### 2.3 监控逻辑缺陷

**原监控逻辑：**
```python
if change_pct > 5%:
    提醒买入
if change_pct < -3%:
    提醒止损
```

**问题：** 
- 等股价跌3%才提醒，**已经晚了**
- 没有**前置预警**机制
- 没有**事件驱动**逻辑

---

## 三、为什么深度分析也失效了？

### 3.1 深度分析的能力边界

深度分析模块能获取：
- ✅ 财务报表（PE/PB/ROE/营收/利润）
- ✅ 技术指标（均线/MACD/KDJ）
- ✅ 估值水平
- ❌ **公司公告**
- ❌ **新闻舆情**

**昭衍新药的情况：**
- 财务上：2025年业绩预增（因为猴价反弹）
- 估值上：PE看起来不高
- **但**：减持公告属于**事件冲击**，不在财务分析范围内

### 3.2 分析的时效性

即使深度分析能发现问题，它的运行频率也不够：
- 盘中监控：每10分钟（只查价格）
- 深度扫描：定时运行（可能几小时一次）
- 公告发布：**实时事件**

**时间差导致错过最佳卖出时机。**

## 八、总结

### 为什么之前没提示卖出？

**根本答案：**
> 系统**没有设计新闻公告监控**这个环节。它只能看到价格变化，看不到导致价格变化的原因。

就像一个人只能通过体温判断是否生病，但看不到病毒感染一样。

### 现在能解决吗？

**可以。** 新闻监控模块已经接入并测试成功。

**但需要：**
1. 接入定时任务（每30分钟扫描）
2. 配置飞书推送（确保及时送达）
3. 完善风险评估（判断公告影响程度）

### 能力够不够？

**技术能力：** 够。AKShare接口可用，关键词匹配有效。

**设计能力：** 之前不够，现在补上了。

**还需要：** 更强的风险评估和操作建议生成能力。
