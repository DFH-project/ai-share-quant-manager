### 2.2 数据流 Review

**新闻监控数据流**:
```
AKShare新闻API
     ↓
关键词匹配（10类）
     ↓
风险评估引擎
     ↓
├─极高风险（95-100分）→ 立即推送
├─高风险（75-90分）→ 建议24小时内处理
├─中等风险（50-70分）→ 需要关注
└─低风险/信息（10-40分）→ 仅供参考
```

**价格监控数据流**:
```
腾讯/新浪行情API
     ↓
实时价格获取
     ↓
├─涨跌幅检查（>5%）→ 异动提醒
└─止损价检查（跌破）→ 止损提醒
```

**持仓联动数据流（新增）**:
```
新闻/价格警报
     ↓
持仓查询（positions.json）
     ↓
├─有持仓 → 计算潜在损失 → 具体卖出建议
└─无持仓 → 一般性关注建议
```

## 三、系统边界分析

### 3.1 能力边界矩阵

| 能力维度 | 系统内 | 系统外 | 边界说明 |
|---------|--------|--------|---------|
| **信息获取** | 新闻/价格/基本面 | Level2/资金流向/龙虎榜 | 系统内完成基础监控，高级数据需付费API |
| **分析决策** | 规则引擎（关键词+阈值） | ML模型/量化策略 | 系统内完成简单规则判断，复杂模型需外部系统 |
| **交易执行** | 飞书消息推送 | 实际下单/条件单 | 系统只提供建议，不自动交易 |
| **风控管理** | 单股风险提示 | 组合VaR/行业暴露 | 系统内单股风险，组合级风控需外部系统 |
| **数据存储** | 本地JSON文件 | 数据库/云端 | 系统内本地存储，不支持多终端同步 |

### 3.2 明确的能力边界

**系统能做的**:
1. ✅ 监控52只自选股的新闻公告
2. ✅ 识别减持/监管/业绩等10类公告
3. ✅ 评估风险等级并给出操作建议
4. ✅ 跟踪持仓盈亏并计算组合风险
5. ✅ 监控技术指标信号（MACD/KDJ等）
6. ✅ 定时自动运行并推送警报

**系统不能做的**:
1. ❌ 自动交易（无法直接下单）
2. ❌ 实时Level2行情（需要付费）
3. ❌ 量化策略回测（无历史模拟）
4. ❌ 组合VaR计算（缺少协方差矩阵）
5. ❌ 行业轮动分析（缺少行业数据）
6. ❌ 多终端同步（本地JSON存储）

### 3.3 边界场景分析

#### 场景1: 昭衍新药减持（系统内处理）
```
✅ 新闻监控 → 发现减持公告
✅ 风险评估 → 高风险85分
✅ 持仓联动 → 查询持仓5%，成本¥25
✅ 操作建议 → "减仓30-50%，设置-5%止损"
✅ 飞书推送 → 即时通知用户
❌ 自动卖出 → 用户需手动操作
```

#### 场景2: 组合风险分析（系统外需求）
```
❌ 组合VaR → 系统无此功能
❌ 行业集中度 → 系统无此功能
❌ 相关性分析 → 系统无此功能
```

#### 场景3: 量化策略（系统外需求）
```
❌ 策略回测 → 系统无此功能
❌ 信号生成 → 只有简单规则
❌ 自动执行 → 系统无此功能
```
